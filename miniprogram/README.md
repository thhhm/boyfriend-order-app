# 原生微信小程序版

这是与 Vite 网页并行的原生微信小程序基础项目，目录为 `miniprogram/`，不会影响网页端代码。

## 导入与配置

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择「导入项目」，项目目录选择本仓库的 `miniprogram/`，AppID 先使用「测试号」或把 `project.config.json` 中的 `wx-placeholder` 替换为你自己的小程序 AppID。
3. 首次导入后，在开发者工具中确认项目根目录是 `miniprogram/`，点击「编译」预览页面。

## 预览与体验版

- 点击工具栏「预览」，用绑定了开发者账号的微信扫码，在真机查看。
- 确认体验无误后，点击「上传」，填写版本号和项目备注。
- 在微信公众平台的「版本管理」中将开发版本提交审核；审核通过后可设为体验版或发布正式版。

## 功能说明

- 已迁移服务菜单、分类筛选、关键词搜索、购物车、数量调整、备注、希望时间和确认提示。
- 购物车使用 `wx.setStorageSync` 持久化，重新打开小程序不会丢失。
- 小程序版**不会伪装发送邮件**。当前确认按钮只展示本地确认页；如果需要通知 `3047292542@qq.com`，请接入微信云函数/自建后端，再由服务端调用邮件服务，并在后端成功后返回结果。
