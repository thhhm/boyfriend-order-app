# 男朋友服务点单

一个移动端优先的中文点单 MVP，使用 Vite、React 和 TypeScript 构建。

## 启动

```bash
npm install
npm run dev
```

然后打开终端显示的本地地址。生产构建使用 `npm run build`，类型检查使用 `npm run typecheck`。

## 已包含

- 服务分类、关键词搜索和响应式服务卡片
- 订单抽屉：调整数量、删除项目、填写时间与备注、基础校验
- 使用 `localStorage` 持久化购物车
- 提交后的确认状态与订单摘要
- 中文语义化按钮、表单标签、键盘可操作控件及移动端布局

## 邮件通知

提交服务请求时，页面会通过 `fetch` 以 AJAX 方式将双方姓名、服务项目与数量、备注信息、期望时间和提交时间发送到 FormSubmit：
`https://formsubmit.co/3047292542@qq.com`。发送期间按钮会进入 loading 状态并防止重复提交；网络或邮件服务失败时会明确提示，不会显示成功状态。

发送成功后才会显示网页确认提示；这表示 FormSubmit 接收了请求，不等同于收件人已经阅读。FormSubmit 首次使用通常会向 `3047292542@qq.com` 发送激活确认邮件，请先点击激活链接，之后服务请求邮件才会正常送达。该方案适用于 GitHub Pages 静态部署，但依赖 FormSubmit 第三方服务和网络，不能保证邮件一定进入收件箱。
