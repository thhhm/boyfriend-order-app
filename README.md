# 男朋友服务点单

一个移动端优先的中文点单 MVP，使用 Vite、React 和 TypeScript 构建。

## 启动

```bash
npm install
npm run dev
```

然后打开终端显示的本地地址。生产构建使用 `npm run build`，类型检查使用 `npm run typecheck`。

## 已包含

- 服务分类、关键词搜索和响应式服务卡片
- 订单抽屉：调整数量、删除项目、填写时间与备注、基础校验
- 使用 `localStorage` 持久化购物车
- 提交后的温暖确认状态与订单摘要
- 中文语义化按钮、表单标签、键盘可操作控件及移动端布局
